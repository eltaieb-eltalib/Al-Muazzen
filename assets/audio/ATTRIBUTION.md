# Adhan audio — attribution & license

The bundled recording `adhan.mp3` (also copied to
`android/app/src/main/res/raw/adhan.mp3` as the notification-channel sound)
is the Wikimedia Commons file **“Azan.ogg”**:

- **Author / performer:** Andrewler (own work, uploaded 2022-09-03)
- **Source:** https://commons.wikimedia.org/wiki/File:Azan.ogg
- **License:** Creative Commons Attribution-ShareAlike 4.0 International
  (CC BY-SA 4.0) — https://creativecommons.org/licenses/by-sa/4.0/
- **Form used:** Wikimedia’s own MP3 transcode of the original OGG file,
  used **without edits** (no trimming, no mixing). Attribution is shown
  in the app under Settings → “صوت الأذان”.

Decision record: on 2026-11-17 the project owner explicitly chose this
recording *because* it is formally licensed. An unlicensed collection
(github.com/abodehq/Athan-MP3 — GitHub API reports `license: null`) was
researched and deliberately **not** used.
